# Support

## Getting help

- **Bugs and feature requests** — open an issue using the templates
  in `.github/ISSUE_TEMPLATE/`.
- **Usage questions** — open a
  [Question issue](../../issues/new?template=question.md) or start a
  Discussion if Discussions are enabled on this repository.
- **Security issues** — see [SECURITY.md](SECURITY.md); do not open a
  public issue.

## Before opening an issue

1. Check the [Troubleshooting guide](docs/troubleshooting/Troubleshooting.md).
2. Search existing issues to avoid duplicates.
3. Include your OS, Node version, and steps to reproduce.
