# 🚀 PIZZEria v3.0.0

**Codename:** Proof — letting it rise before the bake
**Status:** Pre-release
**Release date:** 2026-07-31

## Highlights

Two new ways to reach the kitchen beyond ordering: a reservation
request and a full visual index of the menu.

### Added

- `/reserve` — name, date, time, party size, and notes, sent via
  `mailto:` (same no-backend pattern as `/checkout` and `/contact`).
- `/gallery` — all six menu categories laid out as an illustrated
  grid, using the same wood-fired plate motif as the hero, with a
  category icon standing in for photography.

### Changed

- Header navigation's Reserve and Gallery links (added in v2.0.0, not
  yet wired) now point at real pages.

## Known issues

- Gallery tiles are illustrated placeholders, not real dish photos —
  see `assets/README.md` for the shot list this is waiting on.
- Reservations, like orders, are not persisted or validated against
  actual table availability; they're a request, confirmed by a human
  reading email.

## Upgrade instructions

No action needed — additive on top of v2.0.0.
