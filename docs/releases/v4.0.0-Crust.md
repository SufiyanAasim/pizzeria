# 🚀 PIZZEria v4.0.0

**Codename:** Crust — the finished, baked result
**Status:** Pre-release
**Release date:** 2026-07-31

## Highlights

The last of the four planned releases: multiple locations, and a
performance pass on the two interactive pieces added in v2.0.0.

### Added

- `/locations` — two locations (address, phone, hours) with a
  "Set as My Location" action, persisted in `localStorage`.
- Footer reflects the visitor's active location instead of one
  site-wide address/hours.

### Changed

- `CartDrawer` and `ToppingPicker` load via `next/dynamic`
  (`ssr: false`), deferred until first opened, instead of shipping in
  every page's initial JS bundle.

### Performance

- Fewer components hydrate on first paint for pages that never touch
  the cart or a pizza topping picker.

## Known issues

- Location selection only affects displayed hours/address (footer,
  `/locations`) — it does not filter the menu or change prices per
  location; every location currently serves the same board.
- `/contact`'s static hours line predates the location system and
  hasn't been wired to the active location yet.

## Compatibility

All four releases (v1.0.0 Leaven → v4.0.0 Crust) are additive — no
migration steps between them.

## Upgrade instructions

No action needed — additive on top of v3.0.0.
