# 🚀 PIZZEria v1.0.0

**Codename:** Leaven — the starter
**Status:** Pre-release
**Release date:** 2026-07-31

## Highlights

The first build of PIZZEria: a static-first, wood-fired kitchen
showcase covering pizza, pasta, ramen, sides, dessert, and drinks,
with cinematic hero animation and an optional Turso database behind
the menu.

### Added

- Home, Full Menu, About, Order, and Credits pages.
- Category-tabbed menu grid (Pizza, Pasta, Ramen, Sides, Dessert,
  Drinks).
- GSAP cursor-spotlight hero with floating-ingredient motion.
- Framer Motion "metal shutter" section reveals and animated mobile
  navigation.
- Optional Turso + Drizzle ORM menu backend with a static fallback so
  the site works with zero configuration.

### Security

- No secrets committed; `.env.example` documents the two optional
  Turso variables.

### Performance

- Fully static rendering for all pages at build time (`○ (Static)` for
  every route); no client-side data fetching on first paint.

### UI/UX

- Dark, single-theme "Torrefatto" identity: industrial dark shell,
  trattoria-warm tomato/gold accent, serif display + monospace
  utility type.
- Mobile- and desktop-responsive nav, hero, and menu grid.

### Breaking changes

None — first release.

## Known issues

- The order form opens the visitor's mail client (`mailto:`) rather
  than submitting to a backend; there is no persisted order queue
  yet (planned for v2.0.0 — Knead).
- Dish photography is not yet in place — see
  [`assets/README.md`](../../assets/README.md) for the required image
  list; the site currently ships without food photos.

## Compatibility

- Node.js 20+.
- Works with or without a Turso database configured.
