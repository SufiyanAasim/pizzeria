# 🚀 PIZZEria v4.1.0

**Status:** Pre-release (minor update within the Crust cycle — no new
codename; see `RELEASE.md`, codenames are reserved for major versions)
**Release date:** 2026-07-31

## Highlights

The database stops being read-only: a password-gated admin panel can
now add, edit, and delete categories and menu items directly against
Turso. Alongside it, a UI pass — illustrated icons on every menu card,
a redesigned footer, and a GSAP category marquee on the homepage.

### Added

- `/admin` — category and item CRUD, gated by `ADMIN_PASSWORD`.
- `/api/admin/*` — login, logout, categories, items (see
  `docs/api/API.md`).
- Category icon on every `/menu` card (previously gallery-only).
- Homepage category marquee (auto-scrolling, GSAP), linking to
  `/menu?cat=<slug>`.
- Footer redesign: brand + social, Explore, Visit, and active-location
  columns.

### Security

- Admin session is an HMAC-signed cookie (`src/lib/admin-auth.ts`),
  timing-safe compared, `httpOnly`, `secure` in production. One shared
  password, one role — not a multi-user system. See `SECURITY.md`.

## Known issues

- No image upload in the admin panel — items still use the category
  icon, not a per-item photo. Real photography (`assets/README.md`)
  would need its own upload/storage story first.
- No confirmation email/notification when an admin edits the menu —
  changes go live immediately with no audit trail beyond Turso's own
  history.

## Upgrade instructions

Set `ADMIN_PASSWORD` (and `TURSO_DATABASE_URL` / `TURSO_AUTH_TOKEN`,
if not already) to use the admin panel. No action needed otherwise —
additive on top of v4.0.0.
