# 🚀 PIZZEria v2.0.0

**Codename:** Knead — working the dough into shape
**Status:** Pre-release
**Release date:** 2026-07-31

## Highlights

v2.0.0 turns the menu from read-only into something you can actually
build an order from — pizza topping customization, a persistent cart,
and a review-and-send checkout, all without a payment processor or
backend to run.

### Added

- "Add to Order" on every menu item.
- Topping picker for pizza items — 10 add-ons (extra cheese,
  pepperoni, mushroom, olives, jalapeños, red onion, basil, chili
  flakes, extra nduja, truffle drizzle), each individually priced.
- Persistent cart (`localStorage`), cart drawer with quantity controls
  and per-line removal, item-count badge in the header.
- `/checkout` — reviews cart contents and subtotal, collects name and
  contact info, and sends the itemized order via `mailto:`.

### Changed

- Header navigation gains Gallery, Reserve, and Locations links ahead
  of v3.0.0 / v4.0.0.
- `docker/Dockerfile` now builds on Next's standalone output.

### Fixed

- CI: security audit and Docker build workflows, both broken on
  v1.0.0's first push.

### Security

- Checkout collects no payment information — order details are only
  ever sent through the visitor's own mail client.

### UI/UX

- Topping picker and cart drawer both respect the existing dark
  "Torrefatto" identity — no new colors introduced.

## Known issues

- Cart is device-local (`localStorage`) — it does not sync across
  devices or persist if the visitor clears site data.
- No inventory/availability checks — the menu doesn't know if
  something has sold out.

## Upgrade instructions

No action needed — this is additive on top of v1.0.0. If you'd
previously customized `src/components/menu-grid.tsx`, note it now
takes a `categorySlug` prop to route "Add to Order" correctly.
