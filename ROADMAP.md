# Roadmap

## v1.0.0 — Leaven (current)

Pre-release. Static-first showcase: home, full menu, about, order
form, and credits, with an optional Turso-backed menu.

## v2.0.0 — Knead

- Real order/checkout flow (still no card data handled directly —
  route through a payment provider's hosted checkout).
- Admin view for editing menu items without touching the database
  directly.

## v3.0.0 — Proof

- Reservation/table-booking flow.
- Image gallery for dishes (see `assets/README.md` for the shot list).

## v4.0.0 — Crust

- Multi-location support.
- Performance pass: image optimization, edge caching audit.

## Not planned

- User accounts / authentication — out of scope for a showcase site
  unless the project's purpose changes.
